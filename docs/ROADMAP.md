# Course Roadmap

The course is planned over twelve weeks. Published rows describe the code currently available; future topics may be adjusted according to student progress.

| Week | Focus | Status |
| --- | --- | --- |
| [1](../Week-1/README.md) | Python foundations, collections, loops, functions, and classes | Live notebook, student tasks, and PDF published |
| [2](../Week-2/README.md) | Python practice, matrix operations, and classes | Live notebook, Python tasks, and PDF published |
| [3](../Week-3/README.md) | NumPy, Pandas, and TensorFlow regression | Topic notebooks, datasets, and PDF published |
| [4](../Week-4/README.md) | Visualization and data-analysis review | Topic notebooks and datasets published; shared Week 3 deck |
| [5](../Week-5/README.md) | Simple and multiple regression, model saving, and Streamlit | Notebooks, applications, PDF slides, and a practice copy published |
| [6](../Week-6/README.md) | Laptop-price regression with preprocessing pipelines and Streamlit | Notebook, dataset, saved pipeline, and application published |
| 7 | Evaluation, feature engineering, and tuning | Planned |
| 8 | Neural network foundations | Planned |
| 9 | Computer vision and NLP applications | Planned |
| 10 | Model saving and API serving | Planned |
| 11 | Pipeline engineering and cloud deployment | Planned |
| 12 | End-to-end project | Planned |

The published Weeks 5 and 6 contain local Streamlit examples. Their week guides explain model exports, working directories, and required local path adjustments. Cloud deployment exercises belong to the planned later weeks.
