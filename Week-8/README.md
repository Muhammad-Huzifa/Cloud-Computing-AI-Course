# Week 8: Neural Networks and Transfer Learning

This week introduces convolutional image classification and transfer learning. Start with [CNN_Basics.ipynb](CNN_Basics.ipynb), then complete the [ANN transfer-learning student task](task/ANN_Transfer_Learning_Student_Task.md) using the same labelled image dataset as the instructor notebook.

## Student deliverables

- Completed notebook with visible outputs.
- Baseline and improved-model comparison.
- Evaluation evidence: curves, confusion matrix, classification report, and prediction examples.
- Saved `student_model.keras` plus a short loading/prediction note.

The task is designed to run on a student computer. Use relative paths and keep the dataset unchanged.
