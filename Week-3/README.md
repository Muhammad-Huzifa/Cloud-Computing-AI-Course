# Week 3: NumPy, Pandas, and TensorFlow

Practise numerical operations, explore a housing dataset with Pandas DataFrames, and study a simple house-price regression example in TensorFlow.

## Lessons

| Material | Purpose |
| --- | --- |
| [numpy.ipynb](Code/numpy.ipynb) | NumPy lesson notebook |
| [Housing_DataFrame_Basics.ipynb](Code/Housing_DataFrame_Basics.ipynb) | Load, inspect, filter, group, and save a housing DataFrame |
| [TensorFlow.ipynb](Code/TensorFlow.ipynb) | Simple regression, training, predictions, and evaluation |
| [Week 3 slides](Slides/Huawei_HCCDA_AI_W03.pdf) | PDF slide deck |

## Datasets

| File | Use |
| --- | --- |
| [Housing.csv](dataset/Houses/Housing.csv) | Housing DataFrame exercises |
| [house_price_dataset.csv](dataset/House_Price/house_price_dataset.csv) | House-size and price regression |
| [Titanic_train.csv](dataset/titanic_dataset/Titanic_train.csv) | Additional tabular-data practice |
| [Titanic_test.csv](dataset/titanic_dataset/Titanic_test.csv) | Additional tabular-data practice |

Install the [TensorFlow requirements](../requirements-tensorflow.txt) before running the TensorFlow lesson. The data-loading cells use local Windows paths; follow the [dataset path guide](../README.md#dataset-paths) to point them to your copy of the CSV files. Check the file-loading examples in the NumPy notebook as well.
